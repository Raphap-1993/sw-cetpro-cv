# sw-cetpro-cv

Sistema web institucional y backoffice modular para el CETPRO Cesar Vallejo de Pucallpa.

## Objetivo inicial

Construir un MVP profesional con:

- Web publica institucional.
- Catalogo de programas de estudio.
- Formularios de captacion de interesados.
- Backoffice administrativo para editar contenido clave.
- Base tecnica preparada para crecer hacia un ERP educativo CETPRO.

## Enfoque del proyecto

El proyecto se desarrollara con arquitectura empresarial ligera, priorizando mantenibilidad, seguridad, documentacion y despliegue controlado en VPS con Hestia.
